# 定时执行

技能提供任务说明和辅助脚本。持续运行需要宿主 AI 的定时任务工具，或者团队已经使用的调度器。

## 创建收集任务

用户要求定时运行时，使用宿主平台现有的创建定时任务功能。确认搜索主题、周期、时区、每次上限及 Notion 资源库；用户没有限制主题时采用女性职业发展范围。没有给出时间时询问具体周期，不替用户任意开启长期任务。

保存的任务需要包含技能仓库地址、技能文件位置、网站仓库位置、查询范围、Notion 配置变量名及完成标准。只保存配置名称，不保存 token。使用以下完整提示词，并把时间与范围替换成用户已确定的内容：

> 读取 womencareer-curator 技能仓库中的 SKILL.md，检查网站与 Notion 已收录内容。按已设定主题寻找最多五项新的女性职业资源，阅读官网并核实费用、地区、语言、适用人群及维护状态，编写网站需要的中英文草稿。把通过核实的条目串行提交到现有 Notion 资源库，保持 Published 未勾选，并附上来源与核实记录。查看已有审批意见，避免重复提交不收录的资源。没有新增合格草稿时保持安静；新增审批内容、执行失败或需要用户处理时提供对应链接和必要说明。

定时任务到达上限或出现来源限流时结束本次执行，保存已处理来源和提交 ID，下次读取这些记录继续。同一次执行不在多个进程中写入 Notion。

## 批准后的发布

人工审批后可以在对话中要求发布具体 Notion 页面。用户明确授权自动发布已批准内容时，可以建立独立的发布任务，授权范围包括网站提交、既定合并规则、部署和搜索更新。保存完整提示词：

> 读取 womencareer-curator 的 SKILL.md、references/review.md 和 references/publish.md。查询现有 Notion 资源库中由本技能提交、Published 已勾选且尚未上线的条目。重新读取并校验草稿内容、核实日期和当前审批状态。仅发布通过这些检查的资源，使用网站既定流程完成修改、构建、提交、部署及搜索检查；保留其他内容。没有可发布变化时保持安静；发布成功、失败或需要用户操作时提供相应链接和实际结果。

在这个任务中，网站当前内容与正式部署状态用于判定是否已经发布。不要仅根据本地上次成功标记跳过验证。

## API 与表单

已有 API 可作为定时任务的输入：调用 `collect.mjs --format json`，按官方分页规则获取数据，再执行核实、查重和审批流程。使用来源记录 ID 避免重复。原始 API 响应、表单通知和朋友推荐均不能直接取得发布授权。

如果用户只希望手动转交推荐，直接处理当前批次。需要自动读取 Tally 时，先确认用户已有的导出或集成；本技能不会凭空获取表单后台权限。启用实时 webhook 接收服务属于另外的部署操作，需要具体地址、认证方案及明确授权。
